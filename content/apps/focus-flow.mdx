# Focus Flow

Focus Flow is built for engineers and creators who need uninterrupted concentration blocks.

## Core Features

- **Adaptive Pomodoro Cycles**: Automatically tailors break times based on focus history.
- **System-level DND Sync**: Toggles OS focus modes across phone and desktop simultaneously.
- **Git Commit Sync**: Optionally logs your focused time blocks straight to your daily commit graph.
- **Offline First**: All data remains on-device with optional encrypted iCloud/GDrive backup.
