# GitSnapshot

GitSnapshot lets developers visualize local and remote repositories on mobile devices with high-performance Canvas rendering.

## Core Features

- **Embedded Rust Engine**: Parses massive Git trees in under 50ms natively.
- **GitDiagram Visualizer**: Render branch trees, PR diffs, and DAG charts interactively.
- **Code Review Mode**: Inline syntax highlighting and commit diff inspection on mobile screens.
- **Export Formats**: Export clean SVG, PNG, or Markdown architecture summaries.
