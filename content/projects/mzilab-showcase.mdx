# mzilab.de Showcase Engine

mzilab.de is designed as a zero-server, static-first developer portfolio.

## Key Features

- **Next.js 16 Static Export**: Compiled at build time for instant CDN delivery.
- **GitDiagram Token System**: Ink-like GitHub slate styling in dark mode and crisp zinc tints in light mode.
- **MDX Parser**: Static parsing for mobile app releases, open-source projects, and technical writeups.
