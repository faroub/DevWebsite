# Android XR Glimmer UI Toolkit

An open-source UI toolkit for building augmented HUD interfaces for smart glasses powered by Android XR.

## Highlights

- **Eye-Gaze & Motion Friendly Targets**: Minimized tap targets adapted for glass displays.
- **Low-Power High Contrast**: Designed for OLED glass optics to minimize battery drain.
