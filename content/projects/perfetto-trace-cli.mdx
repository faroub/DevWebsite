# Perfetto Trace Analyzer CLI

Fast command-line tool for analyzing Perfetto traces and diagnosing Android UI jank.

## Features

- **Automated Jank Detection**: Pinpoints main thread freezes over 16ms.
- **Perfetto SQL Query Engine**: Executes custom SQL queries directly against raw trace files.
